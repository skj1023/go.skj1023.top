每日执行版

每个主要行程变化之间都配了 Google Maps 导航按钮。具体班次以当天 Google Maps、JR East、小田急和东京迪士尼官方 App 为准。

10/1周四 · 抵达

成田机场 → 新宿

MU521 · 上海浦东 T1 11:45 → 成田 T2 15:55

机场 → 酒店入境、取行李后前往新宿；首选机场巴士或 Narita Express 转 JR，酒店建议新宿站步行范围内。↗ 去新宿
晚上办理入住后只安排新宿附近晚餐和散步，不再塞入景点。↗ 新宿散步
10/2周五 · 箱根

新宿 ↔ 箱根一日游

从新宿出发，优先安排箱根汤本、大涌谷、芦之湖和箱根神社；当天返回新宿，不住箱根，减少换酒店。

新宿 → 箱根汤本推荐小田急 Romancecar；具体班次和座位以开售后官方时刻表为准。↗ 去箱根
箱根汤本 → 大涌谷乘箱根登山电车、缆车等组合前往；天气和火山管制可能影响线路。↗ 去大涌谷
大涌谷 → 芦之湖／箱根神社下午沿箱根经典路线前往元箱根，安排芦之湖湖畔和箱根神社。↗ 去箱根神社
箱根 → 新宿傍晚回箱根汤本，再乘 Romancecar 或普通列车回新宿；晚上不再换酒店。↗ 回新宿
10/3周六 · 镰仓

新宿 → 镰仓 → 江之岛 → 新宿

安排镰仓大佛、长谷寺、镰仓高校前和江之岛；根据体力在镰仓与江之岛之间取舍，不追求景点全打卡。

新宿 → 镰仓推荐 JR 湘南新宿线前往镰仓；早上出发，给江之岛留足下午时间。↗ 去镰仓
镰仓站 → 镰仓大佛／长谷寺乘江之电到长谷，参观镰仓大佛和长谷寺，再回江之电沿线。↗ 去大佛
镰仓 → 镰仓高校前 → 江之岛沿江之电向江之岛方向移动；镰仓高校前适合短暂停留，不建议长时间排队拍照。↗ 去江之岛
江之岛 → 新宿晚餐后从片濑江之岛／藤泽方向返回新宿，保留交通缓冲。↗ 回新宿
10/4周日 · 搬到舞滨

东京轻松活动 → 舞滨／新浦安

上午在新宿附近慢逛或休息，下午回酒店取行李，前往舞滨／新浦安入住。今晚提前准备迪士尼门票、官方 App 和入园物品。

新宿 → 舞滨带行李优先 JR：新宿 → 东京站 → 京叶线 → 舞滨；东京站换乘步行较长，预留时间。↗ 去舞滨
入住后舞滨站、酒店和 Tokyo DisneySea 之间的路线提前确认；今晚完成入园准备。↗ 去海洋
入园前提前 60—90 分钟到入口，准备充电宝、雨具和舒适鞋。↗ 入园导航
10/5周一 · 迪士尼

全天 Tokyo DisneySea

成人 1-Day Passport 参考价 10,900 日元／人；两人 21,800 日元。当天不安排东京市区购物，把体力完整留给园区。

入园后打开官方 App 查看 Fantasy Springs、Priority Pass 和 Premier Access，再按排队情况调整。↗ 园区地图
晚上回舞滨／新浦安酒店休息，不再安排东京市区活动。↗ 回酒店
舞滨 → 银座推荐 JR 到东京站后转丸之内线／步行；购物前先确定退税和大件寄存位置。↗ 去银座
10/6周二 · 东京购物

舞滨 ↔ 银座／东京站，晚上回舞滨

不搬酒店。推荐把购物主线放在银座、东京站／丸之内，也可以按需求改去新宿；晚上返回舞滨。

银座 → 东京站／丸之内百货、品牌店、东京站一番街和丸之内可按购买目标取舍。↗ 去东京站
东京 → 舞滨购物结束后返回舞滨；购物袋较多时，优先使用车站寄存或直接打车回酒店。↗ 回舞滨
酒店 → 羽田优先查询酒店羽田机场利木津巴士；没有时从舞滨乘电车前往羽田。建议 11:30 前后到机场。↗ 去羽田
10/7周三 · 羽田返程

舞滨 → 羽田机场 T3 → 上海虹桥

MU538 · 羽田 T3 14:30 → 上海虹桥 T1 17:20

机场内办理值机、退税和免税店，国际航班预留充足时间。↗ T3 导航

  • 10/7 从舞滨前往羽田 T3；机场巴士优先，电车为备用。
